# Wide EV v2

GitHub Pagesで動作する個人用の予想・結果記録アプリ。既存のルートサイトを変更せず、`/v2/`に追加する。フレームワーク・ビルド・外部CDN・サーバーは不要。

## 起点

- 既存コミット：`8d2a86b97edd899f0e78b427bbe015ab7861046a`
- 既存バンドルblob：`a336f17599e4eff6fa913de9196078c59e6b8063`
- 計算関数：公開バンドルの795行目、モジュール771
- `modules/core.mjs`の従来6関数は演算順・0の扱い・上限・100円切捨てを維持。
- 元バンドルのモジュールを`tests/legacy-engine.fixture.cjs`で直接実行して比較する。これはテスト専用で、アプリに読み込まない。

## 機能

- 全馬の見積もり、手動の軸、ワイドEV・必要オッズ・ケリー額
- 事前予想の確定スナップショット、改訂履歴、見送り記録
- 全馬の手入力結果、同着・取消・返還、実払戻総額による収支
- 馬／軸ワイドの確率帯分析、Brier・対数損失、候補／非購入の絞り込み
- 統計補正と保守上乗せを分離した入力、日付順の未使用データ検証
- IndexedDBの保存、書き込み競合検知、JSONバックアップと追加インポート
- 旧localStorageを変更しない移行。プリセットと外部Excelは使わない。

## 検証

Node.js 20以上で、依存パッケージのインストールなしに実行できる。

```sh
cd v2
npm test
```

合成データだけを使用する。テストデータを実際の利用記録に混ぜない。

元関数との比較13ケースと10,000入力、スナップショット・結果・収支・JSON・時系列分割を確認する。画面上の操作やIndexedDBの実機動作までテスト済みとみなさない。本作成環境には対応ブラウザーQA機能がないため、その部分は未実施。

## データ

IndexedDB名`wide-ev-v2-records`。サイトのサーバーへ予想・結果を送信する処理はない。IDBの保存失敗を握りつぶさず、確定保存はトランザクション完了後に通知する。同時更新はrevisionで検知する。

同じIDの取り込みでは既存を優先する。元の入力・従来値・統計補正後・購入判断用確率・モデル版を保持する。結果の入力は予想スナップショットを変えない。資金は基準額＋確定収支から毎回算出する。

## 補正の評価

ルール版：`monotone-grid-walk-forward-v1`。固定25候補。前日までの20レース以上で選択し、翌日以降の10レース以上で判定する。同日レースは学習と検証に分けない。保守上乗せ前のBrier改善の区間下限>0、保守上乗せ後・ワイドの下限>=0が条件。レース単位の2,000回ブートストラップは近似であり、保証ではない。

不正な補正出力は基準値に戻して検証に含める。学習対象外の記録を明示する。新しい結果・訂正・移行でモデルを無効化する。ユーザーによる検証・有効化を経て将来日付だけに適用する。既存データの過去予想を後から改善した値で上書きしない。
